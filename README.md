# app-settings

Personal editor and shell config kept in Git for syncing across machines.

| File              | Purpose |
|-------------------|---------|
| `settings.json`   | Cursor / VS Code user settings |
| `keybindings.json`| Keyboard shortcuts |
| `zshrc`           | Oh My Zsh config (theme, plugins, aliases) |

Symlink or copy these into the usual paths for your shell and editor (`~/.zshrc`, Cursor/VS Code `User` folder).
